# 栖光 UI 组件规范

尺寸来源为用户批准的 `design/approved-ui-20260905.json`。本文件只维护当前契约；历史修订见 Git 和 TODO，不再保留两套有效尺寸表。

## 唯一负责位置

- `src/design-system.css`：字体、公共间隔、控件、标题栏及列表几何。
- `src/ui-list.ts`：只读、导航、操作、控件行的统一 DOM。
- `src/app.ts`：页面及业务组合；所有弹层由 `dialogShell` 建立公共标题栏，返回按钮只向该标题栏补入，不另造壳。
- `src/styles.css`：业务布局、像素素材、图表与响应式结构；禁止 font / font-size / font-weight / line-height / letter-spacing。普通文字继承公共角色。
- `design/ui-tuner.html`：只生成候选参数，不自动修改 App 或用户数据。

## 页面：三类，共用外层节奏

| 类型 | 用途 | 结构 |
| --- | --- | --- |
| 一级页 | 今日、任务、记录、轨迹、设置 | 标题，可选操作，正文，底栏 |
| 二级/全屏页 | 状态、目标、记录、设置详情及长编辑 | 返回，标题，可选操作，正文 |
| 上下文弹层 | 短编辑、日期快照、确认、首次引导 | 公共标题栏，正文，操作区；保留背景 |

左右20px，360px及以下默认16px；人工候选可覆盖。标题栏最低44px，标题栏到内容4px，同级内容组16px。顶部、底部和键盘空间使用系统安全区与可用视口。
返回/关闭/更多通过网格和相对布局对齐，不单独绝对定位。大字体允许标题栏自然增高。

## 字体：四级，外加两种明确用途的显示元素

| 角色 | 字号 / 字重 / 行高 | 使用 |
| --- | --- | --- |
| 页面标题 | 16 / 800 / 1.2 | 页面、弹层名称 |
| 组件标题 | 14.5 / 800 / 1.35 | 分组、小节、“正文”“相关记录” |
| 正文 | 12.5 / 400 / 1.5 | 任务名称、记录、输入内容 |
| 辅助 | 11.5 / 400 / 1.35 | 日期、计数、状态 |
| 控件变体 | 正文大小 / 500 | 按钮、小字段标签，不增加字号层级 |
| 数据与图标 | 公共 metric / icon 令牌 | 分数、统计或图形，不用于普通标题 |

日记行高1.55保留为长文阅读变体。普通 strong 不自动把任务变成粗标题；公共标题负责强调。HTML 标签不同不能使同一语义变成另一字号。
所有业务布局 CSS 的字体声明已移除，静态测试禁止重新引入。专用数值和图标的文字规格也集中在公共层。

## 组件：七组基础模板

| 组件组 | 公共结构 | 可调整项 |
| --- | --- | --- |
| 标题栏 | ui-titlebar / ui-page-title / ui-back-button | 标题字号、左右内距、标题到正文 |
| 内容分组 | ui-list-section / ui-list-heading / ui-stack | 标题到内容13px、组间16px |
| 列表 | ui-list-group / ui-list-row | 最低45px、左右20px、上下0、圆角8px |
| 内容容器 | surface / ui-panel / ui-surface-plain | 统一容器内距、边界或无框变体 |
| 表单 | field-label / ui-form-stack / input | 标签间4px、字段间11px、多行最低104px |
| 操作 | button / ui-actions / ui-actions-pair | 可见36px、触控至少44px、按钮间8px |
| 选择 | ui-segmented / ui-filter-tabs | 可见28px、触控至少44px、固定分段或横向筛选 |

列表四种行为共用几何，不是四套皮肤：只读不打卡；导航行进入详情；操作行完成或+1；控件行提供开关或选项。组内只用一个外框和细分隔线；长文自然增高。
人物、日历、热力图、徽章允许专用内部布局，不强塞进列表，但必须复用外层页面、字体及控件。
图片、发送按钮也使用公共 button；不依靠文字宽度碰巧达到最小点击尺寸。

## 间隔归属

页面标题到内容、组件标题到内容、同级分组、字段标签到控件、字段之间、行内内容、操作按钮之间，分别由对应容器负责。不得叠加子项 margin，也不得互借令牌。
行内内容11px，计数到操作2px，操作列55px；普通独立行间4px不作用于组内细分隔线。
复盘输入最低116px，重复标题到星期16px，热力图16px方格/5px间隔，分析列表默认100%内容宽度。400px仅为审查视口。

## 人工调节：一个入口，同一套参数

`design/ui-tuner.html` 保留31项参数、浏览器保存及 JSON 导入导出。旧30项 JSON 只补入按钮间距默认8px，不丢弃已有候选。

| 视图 | 来源 | 边界 |
| --- | --- | --- |
| 统一组件、任务列表、设置分组 | 公共渲染器 + App CSS | 可点击样例，不操作真实业务 |
| 目标、任务编辑、习惯重复、每日/周复盘、日历、成长、分析 | 真实 App DOM 的隔离测试数据快照 + App CSS | 实时调尺寸；不执行业务保存或 AI |

8个手写原型及其专用 CSS 已退出调节页。左右两侧使用同一模板和视口，只有左侧应用候选参数。
快照由 `scripts/capture-ui.mjs` 生成，保存输入值及弹层状态，移除 App 脚本和事件属性；动态样式以惰性数据保存，由外部初始化器逐项恢复，保留生产 CSP。初始化器恢复弹层显示并阻止导航/提交。快照不打开 IndexedDB，也不读写真实记录。
真实页面结构改变后必须重新运行截图命令更新 HTML，不能把旧快照当作最新代码。

建议只依次确认：字体 → 列表密度 → 页面/分组间隔 → 按钮与表单 → 专用图表。颜色、行高和图标大小没有滑块，仍由公共 CSS 管理。

## 自动验证与边界

- `npm test`：静态字体归属、共享组件、调参持久化、真实快照、导入导出、320/400/480px及200%文字。
- `node --experimental-strip-types test/browser.e2e.mjs`：业务、响应式、焦点、删除、AI确认与备份。
- `scripts/capture-ui.mjs`：55场景 PNG + 可调整 HTML，活动页面/弹层的标题栏、列表、方格与已识别文字角色断言。
- `scripts/audit-ui-code.mjs`：CSS 直接尺寸及重复声明的代码清单，不把清单当成全设备通过证明。
- `scripts/prune-ui-css.mjs`：同选择器/同条件覆盖清理的迁移工具，先 dry-run；任何 --write 都必须重新验证。不基于截图猜测死选择器。

本轮55个场景全部有公共标题栏，补齐此前6个未测上下文弹层。已识别文字规格零偏差；旧 CSS 的同条件重复不同值从580降为0，font/font-size/font-weight/line-height/letter-spacing声明为0，业务字体族只允许继承公共字体。
原始1276条目标属性直接尺寸的固定基线是 `design/screenshots/20260906-complete-unification/code-audit.json`，迁移不能刷新此基线。现已1276/1276逐项归类：895条公共令牌、92条安全删除、9条内容自适应、280条必要专用几何；公共组件层直接尺寸为0。专用几何仅限响应式内容边界、日历、图表、人物素材及语义图标，并在账本中保留原因。此固定清单不包括grid轨道、定位偏移和边框等其他属性，不能代替完整设备验收。

`design/ui-dimension-decisions.json` 以基线索引逐条登记决定，同理由的一组仍明确列出每个索引：删除必须给出公共层的完整选择器分支及属性归属；令牌迁移必须对应已定义的公共变量；必要例外必须保留具体用途和原因。不能仅凭数值相同归为一类，44px图片尺寸不等于44px触控区。

`node scripts/audit-ui-code.mjs --strict` 要求全部处理完成且无漂移，并用CSS语法表拦截未知属性、非法属性值和漏登记尺寸；普通测试会阻止新增未登记尺寸、遗漏改动和已删除/自适应规则复活。`scripts/prune-ui-css.mjs --owned-geometry` 只检查无条件公共层的精确同选择器覆盖；`--apply-decisions` 应用已登记的令牌替换和内容自适应删除。两者默认dry-run，明确加`--write`才改文件，执行后须核对Git差异和测试；若写入失败，先修正差异与账本的一致性，不能刷新基线绕过门禁。

默认值不变的迁移还用 `node scripts/compare-ui-css.mjs` 检查55个相同内容夹具：先等待连续两帧字节一致（最多5帧、总预算10秒），再严格比较前后SHA-256；不使用像素容差。统一默认值后的意图性视觉调整改用新截图集 `design/screenshots/20260906-dimension-complete/` 验收：55场景、0预览溢出、统一页面壳与文字角色。工具默认读取暂存区CSS作为前态，因此只适合尚未暂存且预期像素不变的批次；`--self-test` 验证稳定与失败边界。
Android WebView、实际键盘、安全区和设备字体需另做设备验收；浏览器测试不替代真机结论。
