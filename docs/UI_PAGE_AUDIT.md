## 统一设计原则

1. 页面以内容左边线对齐，标题/正文/列表共享宽度。返回按钮占独立44px轨道，相对网格布局。
2. 一个语义一个组件。业务内容不同不创建另一套字体、按钮、圆角；只允许明确的“全宽/标题内”布局变体。
3. 标题粗体，正文与任务名常规字重。统计数字独立层级，不用h标签获得大字号。
4. 外组间16px，标题与内容8px，同行内部8px；由父容器gap控制，子元素不叠加margin。
5. 数据卡所有列等宽，数字和标签共享中心轴。行内容增长允许自然换行，禁止固定高度截断正文。
6. 热力图方格始终正方形，月份/星期/数据共用网格；12周以容器为基准，半年/全年横向滚动，不能把格子压扁。
7. 颜色只表达选中、完成、警示等状态；普通信息不各自套彩色大框。避免容器内再次套同类容器。
8. 空数据诚实呈现，不能为了像设计图制造历史打卡；只有同状态、同视口、同数据才做像素差异结论。
9. 400×866 CSS像素作为主审计视口，另查320px和480px；截图缩放后的物理像素不能直接写成CSS尺寸。

字号与组件数值以 UI_COMPONENTS.md 和 src/design-system.css 为唯一依据；本文件只记录差异与设计决策。
